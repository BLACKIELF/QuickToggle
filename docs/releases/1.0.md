# 轻唤 1.0

源码版本：`1.0.0`。阶段记录：0916v1，相对 0915v1 将本地重做成果统一为 1.0，并加入 GitHub 协作与验证流程。发行日期：2026-09-16。

## 相对 0.0.6

- 应用列表支持搜索、待设置和占用筛选，显示真实快捷键注册状态。
- 设置与帮助移入独立滚动面板，主列表和操作反馈持续可见。
- 应用行支持点击、键盘和辅助功能动作；菜单栏可直接选择应用，重新打开 App 会显示主窗口。
- 改进热键按下／释放门控、Fn 数字组合、冲突提示和异步窗口恢复边界。
- 增加不改动当前配置的隔离预览、三种尺寸布局检查和完整构建自检。
- 构建保留源码提交信息，自检与发行打包使用独立目录。

## 配置兼容

沿用 `com.quicktoggle.app` 和原有偏好格式。升级使用既有应用绑定、设置窗口快捷键、启用状态及占用记录；不要求重新配置或新增账号。

本地验证已覆盖构建、签名、模型、组件路由、搜索筛选、录制与冲突反馈，以及三种窗口尺寸。源代码和自动化检查不能替代每台机器上的全局物理按键、辅助功能、休眠和登录启动验收。

## 构建与验证

```bash
bash selfcheck.sh
bash package.sh
```
